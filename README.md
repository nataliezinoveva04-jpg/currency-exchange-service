# Currency Exchange Service

Сервис для получения и управления курсами валют с использованием API Центробанка РФ.

## О проекте

Этот проект предоставляет REST API для получения актуальных курсов валют, конвертации сумм, расчёта кредитов и управления валютными данными. Сервис автоматически обновляет курсы валют из внешнего API и сохраняет их в локальной базе данных.

### Основные возможности:
- Получение актуальных курсов валют
- Конвертация сумм между валютами
- Расчёт кредитных платежей
- Автоматическое обновление курсов
- Хранение истории курсов в SQLite

## Технологии

- **Python 3.9+** - основной язык программирования
- **Flask** - веб-фреймворк для создания API
- **SQLite** - легковесная база данных
- **Requests** - для HTTP-запросов к внешнему API
- **Pytest** - для тестирования
- **Black** - для автоматического форматирования кода
- **GitHub Actions** - CI/CD для автоматической проверки и тестирования

## Установка и запуск

### Требования
- Python 3.9 или выше
- pip (менеджер пакетов Python)
- Git

### Шаги по установке

1. Клонируйте репозиторий:
`git clone https://github.com/nataliezinoveva04-jpg/currency-exchange-service.git`
`cd currency-exchange-service`

2. Создайте виртуальное окружение:
`python -m venv venv`
`source venv/bin/activate`

Для Windows:
`venv\Scripts\activate`

3. Установите зависимости:
`pip install -r requirements.txt`

4. Запустите приложение:
`python app.py`

Сервер будет доступен по адресу: `http://localhost:5000`

## Тестирование

Для запуска тестов:
`pytest tests/ -v`

Для проверки покрытия кода тестами:
`pytest tests/ --cov=. --cov-report=html`

## API Endpoints

- `GET /rates` - получить все курсы валют
- `GET /rate/<currency>` - получить курс конкретной валюты
- `POST /convert` - конвертировать сумму
- `POST /calculate_loan` - рассчитать кредит
- `POST /update` - принудительно обновить курсы

## CI/CD

Проект использует GitHub Actions для автоматической проверки:

1. **Lint Check** - автоматическая проверка стиля кода с помощью Black
2. **Tests** - автоматический запуск всех тестов при каждом push

Статус сборки отображается в разделе Actions репозитория.
